# 現場操作

## 店家

1. 開 Windows App，完成店名、主機網址與通行碼設定。
2. 建立活動，設定開始、停止及票券失效時間。可建立多場，各場名額獨立。
3. 每款填名稱、可提供的數量，可加規格及照片。
4. 測試手機能開啟主機網址，再列印本場 QR Code。主機要保持開啟。

如果人已經提早排隊，按「現在提早開放」。這只提早開始領號，不會重新編號，也不變更結束與票券失效時間。

## 工作人員

- 透過 Windows App 或手機 App 登入。手機 App 先連接主機，與 Windows 共用同一份即時資料。
- 參加者掃碼、選一款，看到號碼才算完成。
- 要按實體隊伍順序發號，請一次讓一人完成，再換下一人。
- 工作人員掃參加者的「個人票券 QR」，不是現場共用領號 QR。
- 查驗後核對號碼、款式、狀態，按「確認入場」，看到成功提示再放行。
- 若參加者掃碼後改款，舊查驗結果會被拒絕，請重新掃碼。
- 離隊者可取消；取消後不能再入場，也不會補發名額。

## 增減名額

「調整本場名額」先選增加或減少，再選款式與數量。

輸入的是「增加／減少幾張」，不是最後要剩幾張。送出前會顯示本款與本場調整前後的總額。已領、已核銷與已取消的票都算已發出，不能被減掉。

連線失敗時，按同一筆操作重試，不會重複增減。若重新開啟頁面，請先查看現有數量再送出新操作。

## 延長活動

展開「調整活動名稱與時間」，修改停止領號時間及停止後幾分鐘失效。號碼與已發票券保留，所有裝置重新整理後顯示新時間。

票券到失效時間即不可再核銷；主機會每分鐘清除到期票券資料。請在失效前確認現場已完成發放。

## 參加者

掃現場 QR、選一款並領號。領號後在原瀏覽器保留票券，或儲存圖片。入場前最多成功改選一次；目標款式已額滿時原選擇與機會保留。

不需提供姓名、電話或 Email。勿清除瀏覽資料、勿轉傳個人票券。不同瀏覽器或手機可能無法找回原票；有問題請找現場人員查驗。
